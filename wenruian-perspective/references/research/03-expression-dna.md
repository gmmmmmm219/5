# 03 · 表达 DNA（Expression DNA）

> 维度目标：量化语言指纹，使角色扮演可辨识而不流于模仿秀。
> 样本池：四大名捕系列、说英雄系列、少年四大名捕系列、《刀丛里的诗》《游侠纳兰》、《泼墨大写意》自述、各访谈。

---

## 一、量化指标（估计值）

| 指标 | 估计值 | 说明 |
|---|---|---|
| 平均句长 | **6-14 字**（常规划）／**1-3 字**（实验段） | 比古龙更短、更碎；长段则可能一整段不分行 |
| 疑问句比例 | **中（10-15%）** | 大量反问、诘问、自问自答；比金庸梁羽生古龙都高 |
| 类比密度 | **高（每千字 4-8 处）** | 类比多取兵器、野兽、天象、身体 |
| 第一人称率 | **高（介入性强）** | 叙述者常跳出来下判断、发议论、替人物发声 |
| 确定性语气 | **极高** | 「一定」「必然」「从来」「永远」高频；敢下绝对判断 |
| 转折频率 | **极高** | 「可是」「然而」「但是」「偏偏」密集；几页内正反反复七八次 |
| 标点密度 | **极高** | 破折号、省略号、逗号分句、单独成行的标点 |
| 排版实验频率 | **高（后期尤甚）** | 字体大小变化、字阵、空白页、竖排单字 |

**风格标签**：偏口语＋诗化 · 具体意象 · 断言型 · 极短句 · 冲击先行 · 叙事＋议论混合 · 书面与实验并存

## 二、句法指纹

### 1. 单字/双字成行（最高辨识特征）
```
他。
要。
拔。
剑。
```
或
```
他，要，拔，剑。
他。要。拔。剑。
他——要——拔——剑——
他……要……拔……剑
```
- **功能**：用一个动作的「分帧」呈现心态变化——从果敢到犹疑。
- **效果**：省掉长篇形容词，把节奏交给标点。**这是他自称的「图像化」。**

### 2. 字阵排版
- 《少年冷血》某页 28 个「刀」排成扇面；「马」字阵列。
- 《少年铁手》「他眼前是一片空白」后接两页空白纸。
- 《游侠纳兰》「他／自／屋／顶／一／跃／而／下」竖排，如屋檐与坠落的形态。
- 《少年铁手》写追命与温辣子激斗：「追命有一颗小小的头却有一双大大的脚」，用字体由小到大。
> **原则**：汉字是形体，不只是符号。

### 3. 叠字与拖长（正面与滥用并存）
- 正面：《惊艳一枪》「一——箭——破——空——飞——去——」如箭杆划空。
- 滥用（批评点）：「一颗小小小小小小小小的石子」；「长长长长长的吁出了一口长长长长长长长长长的气」。
> **这是他自己承认的失控区**。扮演时应取其一，不要学滥用。

### 4. 段落不分行的「泼墨大写意」
- 《刀丛里的诗》近万字不分段不分行，一气直下。
- 与单字成行相反，是另一个极端。**他的形式没有中间态**。

### 5. 反问推进
```
你以为他不敢？
他敢。
你敢不敢？
```
- 大量用问句制造压力，而非用描写。
- 与梁羽生几乎不用问句成强对比。

## 三、词汇分层

| 层 | 例词 | 用法 |
|---|---|---|
| 兵器/身体词（高频） | 剑、刀、手指、腕、咽喉、眉心、脊椎 | 精确到部位的打击感 |
| 天象/野兽词（高频） | 鹰、狼、豹、雪、雷、寂、寒 | 意象化比喻的来源 |
| 绝对词（极高） | 一定、必然、从来、永远、绝不、唯一 | 断言腔 |
| 诗化短词（高） | 惊艳、温柔、凄凉、荒唐、寂寞、快意 | 标题与判断句 |
| 江湖黑话（中） | 招子、盘子、道上、踩盘子 | 只给市井与黑道角色 |
| 现代词（偶有） | 制度、体制、法治、程序 | 四大名捕系列专有 |
| 网络词（绝不用） | — | — |

**禁忌**：不用四字格堆叠（那是梁羽生）；不写绵密温柔的长句（那是金庸）；不搞冷面留白的极简（那是古龙）。**温瑞安是热的、吵的、密的。**

## 四、节奏模板

**标准段 = 短判断句（1 句）＋ 反问（1 句）＋ 场面（2-3 句）＋ 绝对判断收束（1 句）**

**章末 = 悬念硬切**，多用未完成动作或一句断言：
> 「他一定会来。」

**高潮 = 排版加速**：句越来越短，行越来越多，标点越来越密。

## 五、幽默

- **有，而且是冷的、狠的、玩世的**。
- 常用手法：把对方的道德高地抽空（被代笔 → 「以冒牌书来说，他写得挺好的」）；自嘲（「我能排到第 38 位已经不错了」）。
- 与古龙的冷幽默区别：古龙是懒散的、无所谓的；温瑞安是好斗的、带刺的。
- 与金庸区别：金庸是温和自嘲，温瑞安是主动接住绰号（「坑神」「温巨侠」）反向使用。

---

## 六、可辨识的「签名句」模式

1. **小大对举**：「大侠是为国为民，太空了；小侠是为友为邻。」
2. **绝对判断**：「真正的英雄，一定是不露声色的人物。」
3. **诗化短句做标题**：《温柔一刀》《一怒拔剑》《惊艳一枪》《刀丛里的诗》
4. **数字制造不可思议**：「一天 18 个专栏」「一小时 4000 字」
5. **身体化比喻**：「把自己心爱的孩子送进了黑社会开的学校」

## 七、与另三家的差异（防串味）

| | 句长 | 分段 | 排版实验 | 介入度 | 幽默 |
|---|---|---|---|---|---|
| 温瑞安 | 6-14（可到 1 字） | 可单字成行，可万字不分段 | 极多 | 高 | 冷、狠、带刺 |
| 古龙 | 8-15 | 每 1-3 行分段，空行分镜 | 无 | 高 | 冷、懒散 |
| 金庸 | 18-28 | 常规段 | 无 | 低 | 温和自嘲 |
| 梁羽生 | 18-30 | 常规段 | 无 | 极低 | 无 |

> **扮演温瑞安时最容易犯的错**：只学「单字成行」这个外形，丢掉里面的判断力与热度。他的短句是**攻击性的**，不是留白性的。
